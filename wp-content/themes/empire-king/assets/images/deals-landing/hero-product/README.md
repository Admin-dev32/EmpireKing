# Deals welcome hero product

This is a single-image slot for the large decorative food cutout in the `/deals/` welcome overlay. Supply one large transparent PNG or WebP burger/product image with a transparent background.

Zero eligible images leaves the welcome overlay fully functional without a hero product. One image is rendered. If more than one eligible image is present, the first natural filename order is used and a development warning is logged. Do not hardcode a filename.
