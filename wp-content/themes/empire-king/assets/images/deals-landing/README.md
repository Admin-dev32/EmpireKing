# Deals welcome overlay media

This folder owns the `/deals/` welcome overlay media. Files are user-supplied and repository-owned; image generation is not part of this implementation.

`background/` provides one decorative environmental or food background. `hero-product/` provides one large transparent burger/product cutout. `foreground/` provides transparent promotional-specials artwork for the showcase rail. Deal-card promotional artwork remains separately managed in the WordPress Media Library.
