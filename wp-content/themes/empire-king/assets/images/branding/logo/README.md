# Empire King logo asset

This folder holds the official Empire King header and global brand logo. A user-supplied, approved brand asset is required; do not invent or redesign the logo here.

Prefer a transparent-background SVG, PNG, or WebP with reasonable horizontal logo proportions. JPG and JPEG are also supported. Normally, exactly one primary logo file should live in this folder. Its filename is not prescribed: arbitrary filenames are valid. If several eligible files are present, the theme uses the first in natural filename order; optional numeric prefixes can control that order if needed.

Supply the official logo, or have an existing approved logo cleaned or upscaled in a separate image task.
