# Order Gateway decorative background

This folder holds optional decorative background media for the Home Order Gateway section. It is supporting media, not critical content: the section retains a layered branded fallback when this folder has no eligible image.

Supported formats are WebP, PNG, JPG, and JPEG. The theme selects the first eligible image in natural filename order. Filenames are not prescribed, arbitrary filenames are valid, and numeric prefixes can optionally control selection order.

Use a wide, light, understated image that leaves room for the headline. A cream or off-white paper texture, subtle speckles, or similarly minimal texture is appropriate. The image is presented lightly and should not compete with the foreground; do not use a dark or blurred burger-photo background here.

Copy-ready image prompt for a separate image task: “Create a wide, subtle off-white paper texture for an Empire King Burger website section: warm cream background, restrained natural speckles, lots of clean negative space, minimal visual interference, 16:9 composition, no food, no text, no logos, no gradients, and no brand marks.”
