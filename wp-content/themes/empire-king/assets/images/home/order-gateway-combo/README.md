# Order Gateway combo image

This is a single transparent combo-food image slot for the Home Order Gateway. Place one high-resolution PNG or WebP burger/combo meal cutout in this folder. Transparent background is strongly preferred; avoid large empty transparent margins.

The filename is arbitrary. If no eligible image exists, the combo art is hidden without affecting the layout. If more than one eligible image is present, the theme deterministically selects the first in natural filename order; numeric prefixes may be used to control that order.
