# Home slideshow images

This folder owns the images for the Home slideshow.

- Accepted formats: `.webp`, `.jpg`, `.jpeg`, and `.png`.
- Every eligible image is discovered automatically; no filename list is needed in PHP or JavaScript.
- Files are shown in natural filename order. Numeric prefixes can control the order, for example `01-burger.webp`, `02-family-pack.webp`, and `03-shakes.webp`.
- The mobile display ratio is 1:1. The desktop display ratio is 3:2.
- Images use cover cropping, so keep important subjects and text near the center.
- Use descriptive filenames. Their names are converted into reasonable image descriptions for accessibility.
