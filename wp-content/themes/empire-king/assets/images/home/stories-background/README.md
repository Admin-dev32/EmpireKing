# Home stories background

Keep **one image** here for the decorative Home Latest Stories background.
Supported formats: `.webp`, `.jpg`, `.jpeg`, `.png`. Any filename works.
Images are discovered automatically. If multiple files exist, the first in
deterministic natural filename order is used. With none, the CSS fallback remains.

Use a wide, high-resolution image approximately 2400x1400 or larger. Design for
cover cropping and keep important visual detail near the center; phones crop
more aggressively. Do not bake critical readable text into the background.

This slot is decorative only. Blog featured and article images belong in the
WordPress Media Library, not this folder.
