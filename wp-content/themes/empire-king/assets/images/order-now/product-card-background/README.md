# Shared product image background

Generated static / user-approved theme asset slot. Place **one** WebP, JPG/JPEG, or PNG here, preferably 1:1 square. No required filename; extensions are case-insensitive.

With zero images the existing frame background stays unchanged. One image automatically appears behind actual WooCommerce images in every menu card and product sheet. Product URLs and Media Library records remain unchanged. Opaque product images naturally cover the background.

With multiple images the first filename in case-insensitive natural order wins (for example, background2 before background10); WP_DEBUG emits a development warning. Keep only the physically approved image in this slot.

Jorge will generate and approve the asset separately. Generation brief:

"Create only a premium square restaurant product-display background, 1:1 aspect ratio. No food, no burger, no drink, no text, no logo, no utensils, and no objects. Dark charcoal-to-black environment with subtle deep burgundy/red warmth. Add a soft warm golden/amber glow centered behind where a food product would sit, with very subtle atmospheric smoke and a lightly textured dark restaurant surface. Keep the center visually clean so a transparent food PNG can be layered on top. Darker edges, controlled highlights, premium commercial restaurant advertising finish."
